PDF Reading Tracker

I had a growing pile of documents papers, reports, saved PDFs, that I kept meaning to read and never did, because there was no system. So I built one. The pipeline accepts PDF, TXT, and DOCX files, extracts full text from each, summarizes using an AI model, automatically tags and categorizes the content, and saves everything to a clean CSV. Connected to n8n for automation, Google Sheets as a live knowledge base, and Power BI for visual overviews.

The first project where every piece connected into something I actually use daily. Not a demo, a real tool solving a real problem I had.

Python·Data Pipeline·Automation
Job Application Tracker

Job hunting is chaotic by default, applications scattered across tabs, follow-up dates lost in email threads, no clear picture of where you actually stand. I built a structured tracker to fix that. It centralizes application status, company info, contact details, and key dates into one system, with automated reminders and a clean dashboard view. Designed to remove the cognitive overhead of managing a search so you can focus on the actual work of getting hired.

Built it while actively job-searching. The friction was immediate and personal — which is exactly when you build the best tools.
